What is proven

  • Credential-free safety and control tests pass.
  • Read-only execution, limits, cancellation, and pagination are enforced.
  • The known Prague region semantic mismatch is a regression test.
  • Concurrent service requests use isolated SQLite connections.

What is not yet proven

  • Accuracy confidence intervals on representative held-out schemas.
  • Sustained P95/P99 under production-like concurrent traffic.
  • Live provider degradation and outage behavior.
  • Authorization escape rate in a deployed multi-tenant environment.

Control plane

Version what determines meaning

  • Data-source profile and schema fingerprint
  • Documentation and ontology versions
  • Table and column authorization policy
  • Model and prompt version
  • Frozen evaluation corpus and release thresholds

Request plane

Bound every untrusted operation

  • Question length and request identity
  • Model request deadline and retries
  • Plan ambiguity and confidence
  • SQL statement, object, row, byte, and time limits
  • Redacted audit outcome and metrics

Browser demo versus production runtime

This page uses a public in-memory database. The Python candidate adds filesystem read-only mode, SQLite authorization callbacks, progress cancellation, per-request connections, and durable redacted audit logs.

Release evidence

Generalization and load

Held-out schemas, confidence intervals, adversarial suites, and sustained provider load remain release gates.

Browser-specific safety boundary

The browser copy is disposable and public. SQL runs in a worker against an in-memory database. A slow query terminates the worker; a reload restores the original database. Never substitute customer data here.

Release roadmap

Implementation is ahead of certification.

The remaining work is evidence collection and deployment validation—not another prompt-only iteration.
