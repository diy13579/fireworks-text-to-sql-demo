The latency target is reachable. Accuracy is not there yet.

GPT-OSS 120B achieved a 1.02-second P50, 3.65-second P95, and an estimated $0.0014 run cost. It passed eight of ten execution checks, with stable semantic failures on date formatting and categorical value casing.

Recommendation: use GPT-OSS as evidence for a viable fast path, not as a standalone production model. Add deterministic semantic validation or route risky questions to DeepSeek V4 Pro, which retained 10/10 accuracy.

03 / Quality

Two repeatable semantic failures

Both queries were valid read-only SQL and executed without errors, so the current execution-repair mechanism could not identify them.

q_007 · date representation

Failed in the benchmark and all three reruns. GPT-OSS assumed a two-digit date prefix instead of using the documented ISO year.

substr(date, 1, 2) = '97'

q_010 · categorical casing

Failed in the benchmark and all three reruns. SQLite string matching is case-sensitive for this value.

district.A3 = 'North Bohemia'
General safeguards: require SQLite date functions or half-open ISO ranges for calendar filters, and constrain categorical predicates to exact values supplied in schema documentation. Do not hard-code corrections for these two benchmark questions.

05 / Decision

Use as a fast path with guardrails

GPT-OSS proves the speed and cost case, while DeepSeek Pro currently provides the best observed correctness fallback.

Add semantic linting

Validate date expressions against column formats and categorical literals against documented value sets before execution.

Targets both failures

Escalate risky SQL

Route lint failures, execution errors, and ambiguous joins to DeepSeek V4 Pro instead of returning the fast model's answer.

Recover trust

Rerun held-out evaluation

Do not tune specifically to q_007 and q_010. Add unseen date and categorical cases to test generalization.

Avoid benchmark overfit

Measure the cascade

Report fast-path percentage, combined accuracy, P50/P95, fallback latency, and cost over repeated warm trials.
