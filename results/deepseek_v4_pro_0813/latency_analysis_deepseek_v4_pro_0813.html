DeepSeek V4 Pro 0813 passed all ten execution checks with a 6.09-second P50 and 10.00-second P95. It is faster and cheaper than the cached K2.6 run, and more accurate and cheaper than K3, but it still misses the customer's sub-three-second median target.

Current position: DeepSeek is the strongest balanced single-run candidate, not the final latency solution. Keep it in the shortlist and test DeepSeek V4 Flash or a fast-model cascade against the same 10/10 quality gate.

05 / Decision

Promote to the shortlist

DeepSeek currently dominates K2.6 on the observed quality-speed-cost scorecard, but it is not fast enough for the customer's interactive latency requirement.

Repeat warm-cache trials

Run at least five repetitions per question with a fixed key, reporting cold and warm distributions separately.

Stabilize P50/P95

Benchmark DeepSeek V4 Flash

Use accounts/fireworks/models/deepseek-v4-flash-0731 with the same quality gate. Its list price is materially lower.

Best next speed/cost test

Reduce reasoning output

Test bounded integer reasoning budgets or a non-reasoning path if supported without sacrificing execution accuracy.
